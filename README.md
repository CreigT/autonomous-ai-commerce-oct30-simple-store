## What You Do
1. Open `index.html`
2. Edit only the `CONFIG` block at the top of the `<script>`
3. Replace the Stripe Payment Link with your real one (create free at stripe.com)
4. Push to GitHub
5. Connect the repo to Vercel (or use the deploy button / CLI) — done

No other code changes required. The landing page, product grid, reasonable paywall, and agent status indicators are ready.
